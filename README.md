# Ayah — Qur’an reader

A responsive standalone Qur’an website using the AlQuran Cloud API for Arabic text, translations, chapter metadata, search, and Mishary Alafasy audio.

## Run

Open `index.html` directly, or serve this folder locally:

```sh
npx serve .
```

An internet connection is required for Qur’an content and audio. Bookmarks and reading preferences are stored locally in the browser.
